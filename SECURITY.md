# Security

## Reporting a security issue

Please do **not** disclose security vulnerabilities, API keys, passwords, connection strings, customer data, or other sensitive information in a public GitHub issue.

For the current private beta, security reports should be sent through the private beta contact/feedback channel provided to approved testers.

A dedicated public security contact will be added before broader distribution.

## AI and credentials

CRM Data Assistant may use a participant-provided OpenAI API key. Users are responsible for deciding what information they submit to third-party AI services and for complying with applicable organizational and third-party policies.

## Generated output

CRM Data Assistant is a development-assistance tool. Generated SQL, FetchXML, C#, JavaScript, data-fix instructions, and other output may be incorrect and must be reviewed and tested before use, particularly in production environments.
