# Frequently Asked Questions

## What is CRM Data Assistant?

CRM Data Assistant is an AI-powered Windows developer toolkit for Microsoft Dynamics 365 / Dataverse. It combines natural-language requirements with CRM metadata to assist with common development tasks.

## Is it a chatbot?

No. The product is focused on Dynamics 365 developer workflows such as metadata exploration, FetchXML, SQL, C# plugins, JavaScript ribbon scenarios, test cases, metadata comparison, and dependency discovery.

## Does it understand my CRM schema?

The workflow is designed around loaded CRM metadata, including entities, fields, and relationships, so generated output can be grounded in the target environment.

## Is CRM Data Assistant open source?

No. This public GitHub repository is the product showcase and documentation home. The application source code is maintained privately.

## Can I download the beta from GitHub?

No. The installer is not publicly distributed. Private-beta access is provided to approved participants.

## Do I need ChatGPT Plus or Pro?

No. The current beta uses the participant's own OpenAI API key.

## What operating system is supported?

The current beta targets Windows 64-bit.

## Should generated code be used directly in production?

Generated output should be reviewed and tested by a qualified person before production use.

## Can I report bugs through GitHub?

Public issues must not contain API keys, passwords, connection strings, customer information, screenshots containing confidential information, or other secrets. A dedicated beta feedback path will be provided as the beta funnel is completed.
