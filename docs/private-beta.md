# CRM Data Assistant — Private Beta

CRM Data Assistant v1.0.0 is currently available for private evaluation and testing.

## How access works

The installer is **not publicly downloadable**. Approved beta participants receive access instructions directly.

The beta uses a limited, revocable, non-exclusive, non-transferable evaluation license. The software may not be redistributed, resold, sublicensed, rented, leased, or made publicly downloadable without prior written permission.

## Bring Your Own Key (BYOK)

AI functionality may require your own OpenAI API key. Beta participants are responsible for their OpenAI account, API usage and charges, applicable third-party terms, and deciding what information is submitted to third-party AI services.

## Your responsibilities

You are responsible for authorization to connect CRM environments, databases, and other data sources.

Generated output may contain errors. SQL, FetchXML, C#, JavaScript, data-fix instructions, and other output must be reviewed and tested by a qualified person before use.

## Feedback

Useful beta feedback includes:

- Did the tool save you time?
- Was the generated output technically useful?
- Was anything confusing?
- What was missing?
- Did anything fail?
- Which feature would make you use it again?

Do not include credentials, API keys, customer data, or other secrets in feedback.
